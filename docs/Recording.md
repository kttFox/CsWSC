# CsWSC 記録の仕様

マウス・キーボード操作を記録し、C# スクリプト (`.csws`) を生成します。

## 記録方法 (設定画面)

| 設定 | 対象 | 内容 |
|---|---|---|
| 低レベル記録 | — | 座標ベースで記録する |
| └ マウス座標を相対座標で記録する | 低レベル | ウィンドウのクライアント領域左上を基準にする |
| └ バックグラウンドで実行できる形で記録 | 低レベル | `PostMouse` / `PostKey` / `PostText` で出力 (アクティブ化しない) |
| 高レベル記録 | — | クリックしたコントロールを UI Automation で取得し `ClickItem` で出力 |
| 余分な時間、マウス移動は記録しない | 共通 | ドラッグ以外のマウス移動を捨て、待ち時間を最大 500 ミリ秒にする |
| 記録後クリップボードへコピーする | 共通 | 生成したスクリプトをコピーする |

## 記録しない操作

- 再生中のスクリプトなど、プログラムが送った入力
- CsWSC 自身のウィンドウへの操作
- 末尾の記録停止ホットキーと、末尾のマウス移動
- 30ms 未満の間隔のマウス移動

## 出力の規則

| 操作 | 出力 |
|---|---|
| クリック (200ms 以内・4px 以内で離す) | `Mouse(btn, KeyAction.Click, x, y)` / `wN.Mouse(...)` / `wN.PostMouse(...)` / `wN.ClickItem(...)` |
| ドラッグ | `Mouse(btn, KeyAction.Down/Up, x, y)` |
| ホイール | `Wheel(n, x, y)` |
| 英数字・スペース (1 秒以内の連続入力) | `SendText("...")` にまとめる |
| 修飾キーとの組み合わせ | `Keyboard(修飾キー, KeyAction.Down); Keyboard(キー); Keyboard(修飾キー, KeyAction.Up);` を 1 行で |
| その他のキー、修飾キー単独 (SHIFT 単独は出力しない) | `Keyboard(Keys.X)` |

- SHIFT + 文字以外のキー (矢印キーなど) も同じく `KeyAction.Down` / `Up` で挟んで出力します。
- ウィンドウは最初に使うときに `var wN = GetWindow(タイトル, クラス名) ?? throw ...` を出力し、切り替わったときだけ `wN.Activate()` を出力します。
- 相対座標で記録したドラッグ・ホイールは、ウィンドウが変わるたびに `MouseOrigin(wN);` を出力し、座標をクライアント領域基準で出力します。画面座標に戻るときは `MouseOrigin();` を出力します。
- 待ち時間は前の操作からの経過時間です (最初の操作の前は待たない、50ms 未満は省略)。
  `Move` / `Mouse` / `Wheel` / `Keyboard` / `wN.Mouse` / `wN.PostMouse` / `wN.PostKey` / `wN.PostText` では delayMs 引数 (同時押しは先頭の `Keyboard`) に入れ、それ以外 (`SendText` `wN.ClickItem` など) は `Sleep(ミリ秒)` を出力します。
- 先頭に記録日時と記録方法のコメントを出力します。

## 制限

- IME (日本語入力) の変換操作は文字列としては記録されません。
- バックグラウンド記録でも、ショートカットキー (修飾キーとの組み合わせ) は前面のウィンドウに送られます。
