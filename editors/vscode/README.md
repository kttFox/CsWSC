# CsWSC (VS Code 拡張)

CsWSC スクリプト (`.csws`) と、`#r` で参照するライブラリ (`.cswsl`) を VS Code で編集するための拡張機能です。
`.cswsl` は通常の C# として、実行時と同じ参照と既定の using で解析します (実行はできません)。

- **補完**: 組み込みコマンド (`Mouse` `GetWindow` …)、`Window`・`Control` などのメンバー、.NET の型・メソッド
- **ホバー / 補完の説明**: シグネチャと説明文 (CsWSC のコマンドは日本語、.NET は英語)
- **引数ヒント**: `(` や `,` を入力すると引数の一覧と、入力中の引数を表示
- **エラー表示**: 入力が止まってから 0.5 秒後に、コンパイルエラーと警告に波線を表示
- **実行**: `Ctrl+F5` またはエディター右上の ▶ で、保存してから CsWSC.exe で実行
- **デバッグ実行**: `F5` で、ブレークポイントで止まれるように実行 (C# 拡張機能 ms-dotnettools.csharp が必要)
- **定義へ移動**: `F12` / `Ctrl+クリック` で定義へ移動
  - スクリプト内や `#load` したファイルの変数・関数・クラス
  - CsWSC のコマンド (`Print` など) や .NET の型 (`StringBuilder` など) は、Source Link で GitHub のソースを開く (初回はダウンロードに数秒〜十数秒)
- **名前の変更**: `F2` で、スクリプト内で定義した変数・関数・クラスなどの名前を、使っている箇所ごと変更
- **コードアクション**: `Ctrl+.` で、C# と同じく Roslyn 組み込みのクイック修正 (`using` の追加など) やリファクタリング (`if` の反転など) を実行
- **書式設定**: `Shift+Alt+F` (ドキュメント全体) / `Ctrl+K Ctrl+F` (選択範囲) で、C# と同じく Roslyn で整形
- **色分け**: C# と同じ

## 書式設定と .editorconfig

C# と同じく `.editorconfig` の設定に従って整形します。`.csws` にも当たるよう、セクションに `csws` を含めてください。

```ini
[*.{cs,csws}]
indent_style = tab
csharp_new_line_before_open_brace = none
```

`[*.cs]` だけのセクションは `.csws` には当たりません。インデントの指定が無いときは、エディターの設定 (タブ / スペース、幅) を使います。

## 設定

- `cswsc.exePath`: スクリプト実行に使う CsWSC.exe のパス (未設定なら初回実行時に選択して保存)
- `cswsc.serverPath`: 解析サーバー (cswsc-server.exe) のパス (空なら拡張機能に同梱のものを使う)
- `cswsc.sourceLink`: 「定義へ移動」で CsWSC や .NET のソースを `msdl.microsoft.com` と `raw.githubusercontent.com` からダウンロードする (既定はオン。取得したものは `%LOCALAPPDATA%\CsWSC\SourceLink` に保存)

## 制限

- 1 ファイルごとに独立して解析します。`#load` したファイルの定義は使えますが、開いているほかの `.csws` とは関係なく解析します。
- コードアクションには IDE アナライザーの提案 (`if` に波かっこを追加など) も出ます。エディター上に波線は出さず、`Ctrl+.` のメニューにだけ出ます。
- スクリプトのトップレベルでは、同じコードを通常の C# のトップレベル文として解析してリファクタリングを出します。Roslyn がトップレベル文に対応していないもの (`if` の反転など) は、関数の中でだけ使えます。ダイアログで設定を選ぶもの (コンストラクターの生成など) と、`#load` 先も変更するものは出ません。
- 「名前の変更」は、そのファイルで定義したものだけが対象です (CsWSC のコマンド、.NET の型、`#load` 先の定義は変更できません)。
- 「定義へ移動」で CsWSC や .NET のソースを開くにはネット接続が必要です。フィールドや定数は、ソースの中で宣言を見つけられずファイルの先頭を開くことがあります。
- 解析サーバーが応答しなくなったら、`Ctrl+Shift+P` → `CsWSC: 解析サーバーを再起動` を実行してください。  
動作ログは「出力」パネルの `CsWSC` に出ます。
